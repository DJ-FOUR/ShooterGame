- 面板按钮行用 Horizontal Layout Group：只有 done 时居中，back 出现时自动并排（done 右移）。

## 四、关键实现与决策

1. **单一面板、单一写手**：删掉本地 SettingsPanel，所有入口调同一个 TogglePanel；面板状态 `GlobalMenu.IsOpen` 静态只读，只有 GlobalMenu 写，玩家脚本只读。
2. **prefab 生成法**（GlobalMenu.cs:14）：`[RuntimeInitializeOnLoadMethod(BeforeSceneLoad)]` 静态 Spawn 从 Resources 实例化一次，Awake 里 DontDestroyOnLoad。场景文件不再存持久物体，根治"DDOL + 场景存储"导致的往返切换 panel 叠加。
3. **三层停止机制**：遮罩 Blocker 管 UI 点击（prefab 内 Canvas 第一个子物体，全屏 stretch、黑色半透明、Raycast Target 勾选）；timeScale=0 管世界（AI/物理/动画/粒子）；IsOpen 闸门管直读输入的两处（PlayerMovement.cs:43、MyPlayerShooting.cs:39）。
4. **切场景重应用**（GlobalMenu.cs:36）：sceneLoaded 回调调 ApplyWorldState，防止带面板进 MainScene 时世界不暂停。
5. **OnClick 编辑期限制**：运行时生成的物体拖不进 OnClick，setting 用场景脚本 OpenSettings 中转；prefab 内部按钮不受影响（存 prefab 时引用自动重定向）。
6. **hover 用 unscaledDeltaTime**（ButtonHoverScale.cs:21）：暂停时 UI 动画仍平滑。
7. **鼠标不隐藏、不锁定**：曾按需求加过隐藏+Locked，实测发现本作是俯视角鼠标瞄准（ScreenPointToRay 读 mousePosition），Locked 会把瞄准冻在屏幕中心，已整体撤销鼠标控制。

## 五、当日修复的 bug

1. exit 误绑 OnButtonClick（点了会进游戏）→ 改绑 QuitGame。
2. done 绑 Panel.SetActive 绕过 TogglePanel，关面板后 timeScale 卡 0 → 改绑 TogglePanel。
3. back 绑 SettingsToggle.Toggle（不返回场景）→ 改绑 BackToStart。
4. 往返切换多 panel 叠加（DDOL 与场景存储双实例）→ prefab 生成法。
5. 带面板进 MainScene 不暂停，验证时玩家被敌人打死 → ApplyWorldState + sceneLoaded 重应用。
6. Cursor.Locked 冻住俯视角瞄准 → 移除鼠标控制。
7. prefab 迁移后 setting 的 OnClick 指向 prefab 资产（调用资产方法，运行时实例无反应）→ OpenSettings 中转。

## 六、验证与边界

已验证（MCP Play 实测）：两场景开关链（panel/blocker/IsOpen/back/timeScale 同步）；转向闸门双向（开 0° / 关 39.8°）；射击闸门跨帧累积冻结与恢复；暂停时 hover 到 1.2 倍；三次往返 GlobalMenu 始终单实例；setting onClick 链一下开二下关；back 返回时间恢复。

边界：ESC 与按钮点击用代码调同一方法/onClick.Invoke 模拟，真实键鼠手感需人工 Play；Application.Quit 在编辑器不生效，打包后才真退出；"直接在 MainScene 按 Play 也有菜单"未实测（Spawn 在场景加载前运行，结构上保证）。
